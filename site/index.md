features:
  - title: No server in the path
    icon: Private
    details: Drover connects directly from your device to your own machine over SSH. The developer runs nothing in between, so transcripts, commands and code never reach them.
  - title: Read the session as chat
    icon: Readable
    details: The agent's running session is rendered as a readable conversation, not as raw terminal output.
  - title: Answer prompts as buttons
    icon: Tappable
    details: Permission prompts become tappable buttons instead of something you type into a pane.
  - title: Know when an agent is blocked
    icon: Notified
    details: Notifications tell you an agent is waiting for you. They carry a fixed template and no transcript content.
